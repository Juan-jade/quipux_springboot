# Sistema Académico UCO – Backend

Con ayuda de la IA, se realizo este sistema donde se pueden registrar materias,profes y estudiantes, donde hay multiples posibilidades.
Todo esto fue realizado con Spring boot 3, Maven, Java 17, MySQL, swagger el cual nos permite ingresar los datos a la base de datos 
Panel del profesor:registra notas, asistencia, llegadas tarde y puntos positivos y negativos de sus estudiantes.
Panel del estudiante: consulta sus notas, promedio por materia, tardanzas, ausencias y balance de puntos.

Swagger UI: **http://localhost:8080/swagger-ui.html** · OpenAPI JSON: `http://localhost:8080/v3/api-docs`
